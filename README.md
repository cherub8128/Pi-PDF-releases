# PDF Editor

Windows용 PDF 편집기. 페이지를 정리하고, PDF 안에 이미 있는 텍스트를 직접 고칩니다.

**[최신 버전 내려받기](../../releases/latest)** · [pi-dimension.com](https://pi-dimension.com/)

이 저장소는 **설치 파일 배포용**입니다. 소스 코드는 공개하지 않습니다.

## 기능

**페이지** — 드래그로 순서 변경, 삭제, 회전, 여러 문서를 탭으로 열어 페이지 복사·붙여넣기,
여러 파일 일괄 병합.

**텍스트** — 새 텍스트 상자 추가. 그리고 **PDF에 이미 있는 텍스트의 내용·색·글꼴 수정과 삭제.**
페이지 위를 드래그하면 걸치는 텍스트가 선택되어 `Ctrl+C`로 복사됩니다.

**용량** — 페이지를 지우면 용량도 실제로 줄어듭니다. 큰 이미지 다운샘플링은 선택 사항입니다.

## 다른 편집기와 다른 점

**페이지를 지우면 용량이 줄어듭니다.** 많은 도구가 원본 뒤에 "이 페이지는 이제 참조되지 않음"
이라는 갱신 기록만 덧붙이는 증분 저장을 합니다. 지워진 페이지의 이미지와 글꼴 바이트는 파일에
그대로 남아, 절반을 지워도 용량이 그대로거나 오히려 커집니다. 이 앱은 빈 문서를 새로 만들고
살아남은 페이지만 옮겨 담습니다.

| | 10쪽 문서에서 3쪽만 남겼을 때 |
|---|---|
| 이 앱 | 1422 KB → **427 KB** (−70%) |
| 증분 저장 방식 | 1422 KB → 1422 KB (−0%) |

**텍스트를 고치면 원본 글자가 실제로 사라집니다.** 흔한 구현은 원래 글자 위에 흰 사각형을 덮고
새 글자를 그립니다. 그러면 자국이 남고, 무엇보다 원본 글리프가 파일에 그대로 있어 저장본에서
`Ctrl+F`로 검색하거나 복사하면 **수정 전 텍스트가 나옵니다.** 이 앱은 글자를 그리는 명령 자체를
고쳐 씁니다.

**원본 글꼴을 최대한 지킵니다.** 색만 바꾸거나, 원본 글꼴이 표현할 수 있는 범위에서 내용을
고치면 글꼴을 건드리지 않습니다. 원본에 없는 글자를 새로 입력했을 때만 시스템 글꼴을 서브셋으로
임베딩하며, 어떤 글자 때문인지 입력 중에 알려줍니다.

## 설치

1. [Releases](../../releases/latest)에서 `PDF Editor Setup x.y.z.exe`를 내려받습니다.
2. 실행합니다. 코드 서명을 하지 않아 Windows SmartScreen이 경고를 띄웁니다 —
   `추가 정보` → `실행`을 누르면 설치됩니다.
3. 설치하면 `.pdf` 연결이 등록되어 `연결 프로그램`에서 선택할 수 있습니다.

**요구 사항** — Windows 10 이상 (64비트). Windows 11에서는 창에 acrylic 반투명이 적용되고,
투명 효과가 꺼져 있거나 Windows 10이면 자동으로 불투명 단색으로 표시됩니다.

## 단축키

| | |
|---|---|
| `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 열기 / 저장 / 다른 이름으로 저장 |
| 페이지 위에서 드래그 | 텍스트 영역 선택 |
| `Ctrl+C` | 텍스트를 선택했으면 그 텍스트, 아니면 페이지 복사 (탭 사이 가능) |
| `Ctrl+X` `Ctrl+V` | 페이지 잘라내기 / 붙여넣기 |
| `Esc` | 텍스트 선택 해제 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Ctrl+[` / `Ctrl+]` | 선택한 페이지 좌 / 우 90° 회전 |
| `Delete` | 선택한 페이지 삭제 (텍스트를 선택했다면 그 텍스트) |
| `Ctrl+W` | 탭 닫기 |

## 알려진 제한

- **폼 XObject 안의 텍스트는 편집할 수 없습니다.** 일부 생성기가 본문을 이런 구조로 감싸는데,
  그런 페이지에서는 편집 가능한 텍스트가 잡히지 않습니다.
- **줄 사이 리플로우가 없습니다.** 편집 단위가 한 줄이라, 길어진 문장이 다음 줄로 넘어가지
  않습니다. 폭이 문제라면 `원래 폭에 맞추기`를 켜세요.
- **스캔 문서(팩스 방식 압축)는 다운샘플링에서 제외됩니다.** 이미 픽셀당 1비트 수준이라
  JPEG로 바꾸면 더 커지고 읽기도 나빠집니다.
- 코드 서명 인증서가 없어 SmartScreen 경고가 뜹니다.

## 업데이트

시작할 때 이 저장소의 최신 릴리스 번호를 읽어 현재 버전과 비교하고, 새 버전이 있으면 알려
줍니다. 알림창에서 `이 버전은 다시 알리지 않기`를 체크하거나, `설정 → 정보`에서 확인 자체를
끌 수 있습니다. 버전 번호 외에는 아무것도 전송하지 않습니다.

자동 설치는 하지 않습니다 — 코드 서명이 없는 바이너리를 조용히 교체하는 것은 신뢰할 수 없는
동작이라, 다운로드 페이지만 열어 줍니다.

## 문제가 생기면

앱은 시작 과정을 `%APPDATA%\pdf-editor\main.log`에 기록합니다. 창이 뜨지 않거나 파일이 열리지
않을 때 이 파일과 함께 [이슈](../../issues)를 남겨 주세요.
